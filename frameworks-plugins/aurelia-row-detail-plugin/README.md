## Aurelia-Slickgrid Row Detail plugin
#### @slickgrid-universal/aurelia-row-detail-plugin

Aurelia-Slickgrid Row Detail plugin

### Rendering (v11+)

Row Detail panels always render in an overlay layer above the grid rows. The `rowTopOffsetRenderType` grid option and the Row Detail `renderMode` option have been removed. See the [Row Detail guide](../../docs/grid-functionalities/row-detail.md#overlay-rendering) for configuration and the [v11 migration guide](../../docs/migrations/migration-to-11.x.md#row-positioning-rowtopoffsetrendertype) for upgrade instructions.
