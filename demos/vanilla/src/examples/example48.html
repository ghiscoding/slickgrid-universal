Example 48 - Popups inside Cells
see code

Rows are positioned with transform: translateY() and pinned columns use will-change: transform, so a popup rendered inside a cell is clipped to its row. The "Actions" buttons below open a custom popup appended to grid.getPopupContainer() instead, which escapes the pinned column. The modal button opens a grid inside a <dialog> where the popupContainer grid option is set to the dialog, so the built-in Cell Menu opens over the modal's top layer.
