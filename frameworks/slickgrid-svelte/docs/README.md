# Slickgrid-Svelte Documentation

This documentation covers the Svelte 5 wrapper and the shared SlickGrid Universal features. The Svelte pages explain the wrapper's component API and integrations; the feature pages describe options and behavior shared by the framework wrappers.

## Start here

- [Quick start](getting-started/quick-start.md) — install the wrapper, add a grid, and update its data.
- [Wrapper API](getting-started/wrapper-api.md) — props, bindings, snippets, and lifecycle.
- [Events](events/svelte-events.md) — handle grid events from Svelte.
- [Localization](localization/svelte-i18n.md) — connect i18next or a custom translate service.
- [Custom Svelte components](column-functionalities/svelte-components.md) — build component-based editors and filters.
- [Custom pagination](grid-functionalities/svelte-pagination.md) — supply a Svelte pagination component.
- [Row Detail](grid-functionalities/svelte-row-detail.md) — render Svelte components in detail panels.
- [Examples](https://ghiscoding.github.io/slickgrid-svelte-demos) — explore the Svelte demos and their source code.

Use the [table of contents](TOC.md) to browse all feature guides. For a working application, visit the [Slickgrid-Svelte-Demos repository](https://github.com/ghiscoding/slickgrid-svelte-demos).
